## 🚀 Langkah Praktikum

> 👇 Klik tiap langkah untuk melihat perintahnya.

<details>
<summary><b>1️⃣ Cek instalasi Git</b></summary>

```bash
git --version
```
</details>

<details>
<summary><b>2️⃣ Atur identitas pengguna</b></summary>

```bash
git config --global user.name "gismadian"
git config --global user.email "gismadian14@student.uns.ac.id"
```
</details>

<details>
<summary><b>3️⃣ Clone repositori dari GitHub</b></summary>

```bash
git clone https://github.com/gismadian/Kumpulan-Karya.git
```
</details>

<details>
<summary><b>4️⃣ Masuk ke folder dan salin karya</b></summary>

```bash
cd Kumpulan-Karya
```

Salin semua folder karya dan `README.md` ke dalam folder ini.
</details>

<details>
<summary><b>5️⃣ Cek status repositori</b></summary>

```bash
git status
```
</details>

<details>
<summary><b>6️⃣ Masukkan file ke staging area</b></summary>

```bash
git add .
```
</details>

<details>
<summary><b>7️⃣ Simpan perubahan (commit)</b></summary>

```bash
git commit -m "Upload kumpulan karya"
```
</details>

<details>
<summary><b>8️⃣ Kirim ke GitHub (push)</b></summary>

```bash
git push
```
</details>

**🔄 Alur singkat:**

```
Working Directory ──add──▶ Staging Area ──commit──▶ Local Repo ──push──▶ GitHub
```
